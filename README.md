# 🎮 Contador Gamer 

Projeto desenvolvido em React N ative com Expo.

---

# Preview do APP

O aplicatico possui:
* contador de pontos;
* botão de aumentar;
* botão de diminuir;
* botão de resetar;
* interface estilo gamer;

--- 

# Tecnologias utilizadas

* React native
* Expo
* JavaScript

---

# Como executar o projeto 

## 1. clonar o repoistório
``` 
git clone https://github.com/raissamauricio/contadorGamer.git
```

## 2. Entrar na pasta do projeto
```
cd contadorGamer
```

## 3. Instalar dependências
```
npm install
```

## 4. Rodar o projeto
```
npm start
```
